# JSON

This directory is used by `scripts/JSON_file_to_classes.py`.
By default, the launch configuration in `.vscode/launch.json` calls this script with the following arguments:

- `--input ../json/mcd.json`
- `--output ../json/generated/`
- `--specs ../validation_specs/dv1/`

This directory also contains an example `mcd.json` file (`mcd.json.example`).
